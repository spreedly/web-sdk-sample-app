About Google Pay

The page loads Google's pay.js. SpreedlyGooglePay checks isReadyToPay, draws Google's button, and tokenizes the encrypted Google Pay token with Spreedly while the sheet is open. Only Spreedly can decrypt it (gateway: "spreedly").

Flow Steps
  1. Load pay.js and the selected SDK bundle
  2. Fetch signed auth params from the server
  3. new SpreedlyGooglePay(config) + mount()
  4. Shopper taps → Google sheet opens
  5. SDK tokenizes in onPaymentAuthorized
  6. googlePayTokenGenerated → token + googlePayType
  7. Purchase server-side: TOKENIZED_CARD → simple-purchase; NON_TOKENIZED_CARD → 3DS purchase, then SpreedlyThreeDSLifecycle
Testing notes
  • Google TEST environment — sign in with a Google account enrolled in the test card suite group
  • Serve over https or localhost
  • Until SpreedlyGooglePay reaches the rc CDN, run the SDK locally — see docs/google-pay/DEMO_GUIDE.md
  • Auth params are single-checkout: New checkout fetches fresh ones
