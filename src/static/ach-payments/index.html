About ACH Payments

ACH payments tokenize a US or Canadian bank account. With SpreedlyACH the routing and account numbers are entered in Spreedly-hosted iframes and tokenized from inside them — the merchant page never touches the raw numbers, the same secure-field model as card number and CVV. After the SDK emits tokenGenerated, the merchant backend runs a purchase on a gateway that supports ACH.

Flow Steps
  1. Load the hosted-fields SDK and create new SpreedlyACH(auth)
  2. Call inAppElements({ routing, account }) to mount the secure fields
  3. Buyer types the numbers into the iframes; name/type stay plain merchant inputs
  4. Call submit(formData) with only the non-sensitive fields
  5. Listen for tokenGenerated → token + last4
  6. Send token to backend → run gateway purchase

The older setupACHPayment / submitACHPayment API, where the merchant collected the numbers itself, still works but is deprecated in favor of these secure fields.
