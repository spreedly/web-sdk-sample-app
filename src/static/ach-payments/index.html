Flow Steps
  1. Load the Express Checkout SDK and create new SpreedlyACHForm(auth)
  2. Call mount({ parentContainerId, uiConfig }) to show the form
  3. Buyer fills in the form and presses its submit button
  4. The form tokenizes inside the iframe → tokenGenerated with Spreedly's transaction (tokenResponse)
  5. If shouldRetain is true (Allow retaining on, box ticked) → backend retains the token
  6. Send token to backend → run gateway purchase
  1. Load the hosted-fields SDK and create new SpreedlyACHFields(auth)
  2. Call inAppElements({ routing, account }) to mount the secure fields
  3. Buyer types the numbers into the iframes; name/type stay plain merchant inputs
  4. Call submit(formData) with only the non-sensitive fields
  5. Listen for tokenGenerated → Spreedly's transaction (tokenResponse)
  6. Send token to backend → run gateway purchase
