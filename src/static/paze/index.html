About Paze

Paze is a bank-backed digital wallet. The merchant loads the Paze SDK script; Spreedly's SpreedlyPaze class orchestrates eligibility checks, the checkout popup, and securedPayload retrieval.

Flow Steps
  1. Load Paze SDK script tag on the page
  2. Pass clientConfig from merchant UI into SpreedlyPaze
  3. Initialize SpreedlyPaze with auth params
  4. Check customer eligibility (optional)
  5. Launch Paze checkout popup
  6. Complete flow to obtain securedPayload
  7. Create Spreedly payment method (POST payment_methods)
Button guidelines
  • Show the branded Paze button on page load (static mode)
  • Place it where checkout starts — cart, product, or payment page
  • Use Express Pay to reduce clicks after wallet selection
  • Let Paze collect shipping via Change Shipping Address
