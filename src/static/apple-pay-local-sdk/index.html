How this page works
  1. The page loads Apple's apple-pay-sdk.js and the Spreedly SDK.
  2. onValidateMerchant calls this server's /api/v1/apple-pay/validate.
  3. getAuthDetails calls /api/v1/auth/params for every attempt.
  4. The SDK turns Apple's token into a Spreedly payment method.
  5. The page charges it with /api/v1/simple-purchase on the test gateway.
