Apple Pay headless (local SDK)

This page runs Apple Pay with its own code, as a merchant with an existing Apple Pay integration would. The SDK only turns Apple's approved payment into a Spreedly payment method, with SpreedlyApplePay.tokenize(). Test data only.

How this page works
  1. The page draws Apple's button and opens the sheet with its own ApplePaySession.
  2. onvalidatemerchant calls this server's /api/v1/apple-pay/validate.
  3. When the shopper approves, the page gets fresh auth from /api/v1/auth/params and calls SpreedlyApplePay.tokenize().
  4. The page charges the token with /api/v1/simple-purchase, then calls Apple's completePayment itself.
session.onpaymentauthorized = async event => { const { result, error } = await SpreedlyApplePay.tokenize({ payment: event.payment, authDetails: await getFreshSpreedlyAuth(), }); if (error) { session.completePayment({ status: ApplePaySession.STATUS_FAILURE }); return; } // Charge result.token on your server, then: session.completePayment({ status: ApplePaySession.STATUS_SUCCESS }); };
